Concepto

Librería vs Framework

Librería

Conjunto de objetos/funciones para una tarea específica

Ej: manejo de fechas, validación

Framework

Define una forma de construir aplicaciones y provee herramientas

Ej: Angular, .NET, Ruby on Rails, Django

Angular es un framework — define estructura, convenciones y herramientas completas

Control Flow

Forma moderna en Angular 17+

18
Control Flow

@if, @for, @switch

// @if / @else @if (book.inStock) { <span>Disponible</span> } @else { <span>Sin stock</span> }
// @switch @switch (status) { @case ('active') { <span>Activo</span> } @case ('inactive') { <span>Inactivo</span> } @default { <span>Desconocido</span> } }
// @for con track @for (book of books; track book.id) { <app-book [book]="book" /> } @empty { <p>No hay libros</p> }

track es obligatorio — mejora el rendimiento de la lista

19
Control Flow

Directivas legacy

*ngIf / *ngFor

Todavía funcionan en Angular 21 por retrocompatibilidad

Se mencionan porque aparecen en proyectos existentes y exámenes

  • Requieren importar CommonModule
  • O importar NgIf, NgFor individualmente

Criterio: Usar @if/@for en proyectos nuevos. Reconocer legacy en proyectos existentes.

22
Comunicación

input() y output()

input() — Recibir datos

import { input } from '@angular/core'; // Hijo book = input.required<Book>(); highlight = input<boolean>(false);

output() — Emitir eventos

import { output } from '@angular/core'; addToCart = output<Book>(); onAdd() { this.addToCart.emit(this.book()); }
// Uso en el template del padre <app-book [book]="selectedBook" (addToCart)="handleAdd($event)" />

Legacy: @Input() / @Output() decoradores siguen funcionando

21
Lifecycle

ngOnInit y ngOnDestroy

ngOnInit

Se ejecuta una vez, después de que Angular inicializa los inputs

Lugar correcto para:
Llamadas HTTP iniciales, lógica de inicialización

No usar el constructor para lógica de negocio

ngOnDestroy

Se ejecuta antes de que el componente sea eliminado del DOM

Lugar correcto para:
Cancelar subscriptions, limpiar timers

export class BookComponent implements OnInit, OnDestroy { ngOnInit() { } ngOnDestroy() { } }
