01
Guards & Build

Guards funcionales

¿Qué hacen?

  • Protegen rutas: deciden si el usuario puede acceder
  • Devuelven true / false / UrlTree (redirect)
  • Se ejecutan antes de instanciar el componente
  • Tipos: canActivate, canMatch, canDeactivate, resolve

En Angular moderno

  • Son funciones (CanActivateFn) — no clases
  • Usan inject() para acceder a servicios
  • ng g g guards/auth → guard funcional por defecto (v17+)

Los guards de clase (implements CanActivate) están deprecados desde v15.2.

01
Guards & Build

Anatomía de un guard funcional

Definir el guard

// guards/auth.guard.ts import { CanActivateFn, Router } from '@angular/router'; import { inject } from '@angular/core'; export const authGuard: CanActivateFn = (route, state) => { const router = inject(Router); const token = localStorage.getItem('token'); if (token) return true; return router.parseUrl('/login'); };

Registrar en la ruta

// app.routes.ts { path: 'add-book', component: AddBookComponent, canActivate: [authGuard] }

Tip: devolver router.parseUrl('/login') es preferible a navegar imperativamente — Angular sabe que es un redirect del guard.

📦
Guards (Legacy)

Guards de clase — solo referencia

Estilo anterior (v14 y previos)

// NO usar en proyectos nuevos @Injectable({ providedIn: 'root' }) export class AuthGuard implements CanActivate { canActivate(): boolean { return true; } }

¿Por qué cambió?

  • Las funciones son más simples — no necesitan @Injectable ni DI implícita
  • inject() funciona en cualquier contexto reactivo
  • Menos boilerplate, mismo poder
  • Mejor tree-shaking — el guard solo se incluye si la ruta lo usa

Si lo ves en código: seguramente es un proyecto migrando desde Angular ≤ 14. Migrar a CanActivateFn es directo.

02
Formularios

Template-Driven — los 3 modos de ngModel

// 1. Sin binding — registra el control en NgForm (leer en form.value) <input name="username" ngModel required> // 2. Two-way binding — propiedad del componente sincronizada <input name="acceptTerms" [(ngModel)]="acceptTerms" type="checkbox"> // 3. One-way binding — valor inicial, sin actualización inversa <input name="title" [ngModel]="book.title" required>

name es obligatorio: sin name, ngModel no se registra en el NgForm y el control no aparece en form.value.

02
Formularios

Estados del form & clases CSS

Las 3 dimensiones del estado

  • ng-valid / ng-invalid — pasa los validadores
  • ng-touched / ng-untouched — el usuario interactuó (blur)
  • ng-dirty / ng-pristine — el valor cambió

UX tip: mostrar errores solo cuando el campo está touched — no en el primer render.

Estilar errores en CSS

/* solo cuando el usuario lo tocó */ input.ng-invalid.ng-touched { border-color: red; } input.ng-valid.ng-touched { border-color: green; }
02
Formularios

Reactive — FormBuilder

El estándar de la industria — más corto que new FormGroup({...}) y type-safe.

import { FormBuilder, Validators } from '@angular/forms'; import { inject } from '@angular/core'; export class AddBookComponent { private fb = inject(FormBuilder); form = this.fb.group({ title: ['', [Validators.required, Validators.minLength(3)]], author: ['', Validators.required], year: [null as number | null, Validators.min(1000)], }); onSubmit() { if (this.form.valid) { console.log(this.form.value); this.form.reset(); } } }
02
Formularios

Typed Reactive Forms (v14+)

FormControl individual

// el tipo se infiere del valor inicial title = new FormControl<string>( '', { nonNullable: true } ); // form.value.title es string (no any)

nonNullable: true — el control nunca es null, ni después de reset().

Acceso a valores y estado

// valor this.form.get('title')?.value // estado por control this.form.get('title')?.invalid this.form.get('title')?.touched this.form.get('title')?.hasError('required') // estado del form completo this.form.valid this.form.value

02
Formularios

Mostrar mensajes con hasError()

<!-- template --> @if (form.get('title')?.hasError('required') && form.get('title')?.touched) { <span class="error">El título es requerido</span> } @if (form.get('title')?.hasError('minlength')) { <span class="error">Mínimo 3 caracteres</span> }

Patrón: hasError('clave') + touched → no avergonzar al usuario antes de que toque el campo.

02
Formularios

Custom validator — ValidatorFn

Función reusable

// validators/isbn.validator.ts export function isbnValidator(): ValidatorFn { return (control: AbstractControl) : ValidationErrors | null => { const clean = (control.value ?? '').replace(/-/g, ''); if (!clean) return null; const ok = /^\d{10}$/.test(clean) || /^\d{13}$/.test(clean); return ok ? null : { isbn: true }; }; }

Usar en FormBuilder

form = this.fb.group({ isbn: ['', isbnValidator()], });

Regla: retornar null si es válido, { clave: ... } si no. La clave es la que después se usa en hasError().

02
Formularios

El mismo validator en Template-Driven

Envolver la ValidatorFn en una directiva — sin duplicar lógica.

// validators/isbn-validator.directive.ts @Directive({ selector: '[isbnValidatorDirective]', standalone: true, providers: [{ provide: NG_VALIDATORS, useExisting: IsbnValidatorDirective, multi: true }], }) export class IsbnValidatorDirective implements Validator { validate(control: AbstractControl): ValidationErrors | null { return isbnValidator()(control); // reutiliza la misma lógica } } <!-- template-driven --> <input name="isbn" ngModel isbnValidatorDirective>

Misma lógica, dos formas de usarla: ValidatorFn en Reactive, directiva en TDF. Sin código duplicado.

03
Servicios

Qué es un servicio

Idea

  • Clase con lógica de negocio reutilizable
  • Separación de responsabilidades: componente = vista, servicio = datos
  • Vive una sola vez (singleton) y se comparte por DI
  • Generar: ng g s services/book

En la próxima clase: profundizamos en el sistema de DI completo — providers, inyección jerárquica y tokens.

Anatomía

// services/book.service.ts @Injectable({ providedIn: 'root' }) export class BookService { private books = booksMock; getBooks() { return this.books; } getBookById(id: number) { ... } addBook(b: Book) { ... } } // en un componente private bookService = inject(BookService);
